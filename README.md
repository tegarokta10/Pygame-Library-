# 🐦 Fluffy Bird — Pygame Learning Project

Fluffy Bird is a simple Flappy Bird-style game made with **Python and Pygame**.

This project was created to learn and practice the fundamentals of game development using the Pygame library.

## 🎮 Features

- Player movement and flap mechanics
- Obstacles
- Collision detection
- Score and highscore system
- Menu and gameplay states
- Basic animations
- Sound effects and background music
- Delta-time based movement
- Asset management

## 📚 What You Can Learn

This project can be used as a simple reference for learning:

- Python with Pygame
- Game loops
- Functions and classes
- State management
- Player movement
- Collision detection
- Game objects
- Events and input
- Basic animation
- Audio
- File and asset management
